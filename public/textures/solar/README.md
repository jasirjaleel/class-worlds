# Optional planet photos

Space Fleet draws every planet with code. To use real photo textures instead,
download these 2K files from https://www.solarsystemscope.com/textures/ and put
them in this folder (the names must match exactly):

2k_sun.jpg, 2k_mercury.jpg, 2k_venus_atmosphere.jpg, 2k_earth_daymap.jpg,
2k_earth_clouds.jpg, 2k_moon.jpg, 2k_mars.jpg, 2k_jupiter.jpg, 2k_saturn.jpg,
2k_saturn_ring_alpha.png, 2k_uranus.jpg, 2k_neptune.jpg

Any file that is present is used automatically; missing ones fall back to the
drawn surface.

Credit (required by the licence, shown on the Space Fleet screen when photos
are present): textures by Solar System Scope (solarsystemscope.com),
